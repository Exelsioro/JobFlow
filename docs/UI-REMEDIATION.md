## Результат

Изменения из таблицы реализованы. Обзор разделяет три причины для действий: нет подтверждения отправки, подготовка остановлена, материалы ожидают проверки. Счётчик и список для каждой причины используют один профиль и включают тестовые отклики. Проверено, подготовлено и отправлено — отдельные метрики прогонов. Недоступный раздел не изображается пустым: остаётся последний полученный снимок либо сообщение об отсутствии данных.

## Как проверить повторно

1. В каталоге [веб-приложения](../src/JobFlow.Web/) выполнить `npm run build`.
2. Из корня выполнить `dotnet run --project tests/JobFlow.Smoke -- --workspace-ui` с установленным Chromium для Playwright. [Тест](../tests/JobFlow.Smoke/WorkspaceUiSmoke.cs) загружает собранный интерфейс, подменяет API синтетическими ответами и не использует рабочую базу или площадки.
3. На локальном экземпляре открыть обзор, пройти из очереди в карточку, затем вернуться в список. В истории Workflow раскрыть подробности прогона. Для этой проверки не нужно запускать Workflow или отправлять отклик.

Дополнительно в Chromium проверены первый запуск, обязательные поля при сохранении с клавиатуры, прямые ссылки, мобильное меню и отсутствие горизонтальной прокрутки страницы на ширине 390 px. На рабочем экземпляре проверены обзор, карточка отклика, список откликов и вакансии в режиме только чтения. Результаты проверки интерфейса не подтверждают авторизацию на внешних площадках или доставку резюме.

В проверке с задержанным ответом три дополнительных срабатывания таймера не запустили параллельные опросы, а ручное обновление не было перезаписано устаревшим результатом. Итоговый объём стартовой сборки — 495,46 кБ при пороге предупреждения 500 кБ. Порог не менялся.
